# 📌 Folder Pins

**Часто используемые папки — всегда под рукой в Проводнике VS Code.**

Закрепляй нужные папки в отдельной секции, раскрывай вложенные каталоги и открывай файлы, не разыскивая их в большом проекте. Закрепления сохраняются после перезапуска и отдельно для каждого рабочего пространства.

## Установка — без сборки

Требуется **VS Code 1.85 или новее**. Расширение устанавливается из файла VSIX; искать его в Marketplace не нужно.

1. **[Скачай Folder Pins 0.1.1](https://github.com/xmxmxmxmxmxmxmxmxmxm/vscode_folders_pins/raw/refs/heads/main/dist/folder-pins-0.1.1.vsix)**.
2. В VS Code открой **Расширения** (`Ctrl+Shift+X`, на macOS — `Cmd+Shift+X`).
3. Нажми **⋯** в заголовке панели → **Install from VSIX… / Установить из VSIX…**.
4. Выбери скачанный файл `folder-pins-0.1.1.vsix`.
5. Если VS Code предложит перезагрузить окно, нажми **Reload Window**.

Также можно установить через терминал, находясь в папке со скачанным файлом:

```sh
code --install-extension folder-pins-0.1.1.vsix
```

В Code OSS команда может называться `code-oss`.

При обновлении установи новый VSIX тем же способом: удалять предыдущую версию не нужно, закрепления сохранятся.

## Как пользоваться

1. Открой проект в VS Code.
2. Нажми **ПКМ по папке → Закрепить папку**.
3. В Проводнике появится секция **Закреплённые папки**. Раскрывай папки и открывай файлы прямо из неё.
4. **Перетащи заголовок секции выше основного дерева**, чтобы нужные папки всегда были сверху.

### Возможности

- **Несколько папок за раз:** выдели их в Проводнике и выбери «Закрепить папку».
- **Выбор через диалог:** кнопка закрепления в заголовке секции позволяет выбрать папки, в том числе вне проекта.
- **Быстрое открепление:** нажми кнопку рядом с закреплённой папкой. Файлы и папки не удаляются.
- **Возврат к оригиналу:** ПКМ по элементу → «Показать в основном дереве» для элементов внутри открытого проекта.
- **Отдельные закрепления для каждого проекта:** список хранится в состоянии рабочего пространства VS Code.
- **Обновление дерева:** изменения внутри рабочего пространства подхватываются автоматически. Для внешних папок используй кнопку «Обновить».
- **Удалённые файловые системы:** расширение использует файловый API VS Code, а не только локальные пути.

> Интерфейс расширения сейчас на русском языке.

## Важно знать

- Расширения не могут переставлять папки в штатном дереве VS Code. Folder Pins добавляет **отдельную секцию в том же Проводнике**; её расположением управляет сам VS Code.
- Дерево закреплений показывает все файлы, включая скрытые: `files.exclude` и `.gitignore` к нему не применяются.
- Открепление папок и команда «Открепить все папки» меняют только список закреплений, а не файлы на диске.

## Разработка

### Запуск из исходников

```sh
git clone https://github.com/xmxmxmxmxmxmxmxmxmxm/vscode_folders_pins.git
cd vscode_folders_pins
code .
```

Нажми **F5** и при необходимости выбери **Folder Pins: запуск расширения**. В новом окне **Extension Development Host** открой проект и закрепи папку через контекстное меню.

Для запуска через F5 зависимости и сборка не нужны: расширение написано на JavaScript и использует встроенный API VS Code.

### Тесты

Требуется Node.js 20 или новее. Для сборки рекомендуется актуальная LTS-версия Node.js.

```sh
npm test
```

Тесты проверяют хранение закреплений, сортировку и связи родителей в дереве, необходимые для `TreeView.reveal`. Интерфейс проверяется вручную в Extension Development Host.

### Сборка VSIX

```sh
npm ci
npm run package
```

В корне проекта появится `folder-pins-0.1.1.vsix`, который можно установить через **Install from VSIX…**.
